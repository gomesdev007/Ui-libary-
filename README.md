Rayfield Gen3 Compact

A compact, community-modified interface based on Rayfield Gen3.

Rayfield Gen3 Compact is a UI customization project focused on a cleaner, more compact layout and improved usability across different screen sizes.

Overview

This project introduces visual and layout adjustments to the original interface, with an emphasis on compact dimensions and mobile-friendly presentation.

Features

- Compact interface layout
- Adjusted window dimensions and proportions
- Customized visual styling
- Mobile and desktop usability considerations
- Compatibility intended to follow the original library's API

Features and compatibility may vary depending on the source version and modifications.

Installation

If you have permission to use and redistribute the source, you can load the published Lua file as follows:

local Rayfield = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/gomesdev007/Ui-libary-/refs/heads/main/Rayfield_Gen3_Compact.lua"
